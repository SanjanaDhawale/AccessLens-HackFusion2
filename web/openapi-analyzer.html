OpenAPI Specification Analyzer

Inspect API endpoints, HTTP methods, authentication requirements and declared roles. File parsing runs in your browser. No requests are sent to the target API.

1. Upload an OpenAPI specification

To use ConnectedCar: open its OpenAPI JSON, save the file, then upload it here while the local API is running.

2. Endpoint inventory

Authentication schemes and scopes are declarations from the specification, not proof of enforcement. Roles are shown only if explicitly declared with x-roles or x-required-roles. No vulnerability testing occurs here.

3. Configure expected access rules

Choose an endpoint row, then assign the access policy approved by the API owner. Rules are saved in this page until refreshed and can be exported as JSON. They do not change the API or run tests.
