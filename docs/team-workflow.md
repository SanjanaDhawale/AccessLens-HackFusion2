# Team workflow

## Branch ownership
- feat/connected-car-api — Member 1: ConnectedCar target API
- feat/security-engine — Member 2: parser, scope, policies, sessions, detectors
- feat/dashboard — Member 3: frontend dashboard
- feat/evidence-reporting — Member 4: evidence, risk, reports, integration tests

## Rules
1. Work only on your assigned feature branch.
2. Pull the latest develop before starting and before opening a PR.
3. Commit small, meaningful changes.
4. Open PRs into develop; do not push feature work directly to main.
5. Do not change shared contracts without notifying the team.
6. Run tests and verify locally before requesting review.
